# Установка и запуск (Windows)

Дневник работает на вашем компьютере. Данные не уходят в интернет: логи терминала читаются
только на чтение, база лежит в папке `data/`.

## Что нужно

- Терминал **CScalp** (FSR Launcher), который пишет логи (по умолчанию
  `C:\Program Files (x86)\FSR Launcher\SubApps\CS\Log`).
- **Python 3.12 или новее** с сайта python.org. При установке отметьте галочку
  **Add python.exe to PATH**.

## Запуск

1. Распакуйте архив в любую папку (не в `Program Files`).
2. Дважды щёлкните **`start.bat`**. При первом запуске он сам создаст окружение и скачает
   нужные библиотеки (нужен интернет, 1–3 минуты).
3. Откроется браузер с дневником: <http://127.0.0.1:8777>. Окно с чёрным фоном не закрывайте,
   пока пользуетесь дневником. Закроете его, и дневник остановится.

Каждый запуск `start.bat` сначала подтягивает всю историю из логов, потом следит за сегодняшним днём.

## Первые шаги

- **Капитал.** Откройте «Итоги месяца» и заполните вверху: «Старт» (стартовый капитал) и «Сейчас»
  (сколько на счёте сейчас). Если терминал показывает лимит с плечом, укажите свой реальный
  капитал: дневник сам подберёт коэффициент.
- **Связки.** На главной отметьте сделки галочками и нажмите «Создать из выбранных».
- **Комиссии за переносы и фандинг.** На странице отчёта внизу есть форма «Добавить движения по
  счёту»: вставьте строки из выписки брокера.

## Ручные правки без программиста

Всё, что нужно поправить в статистике, делается на странице «Итоги месяца», программа для этого
не нужна:

| Что нужно | Где это сделать |
|---|---|
| Стартовый капитал, сколько на счёте сейчас, пик | Поля «Старт», «Сейчас», «Пик» вверху страницы, кнопка «Сохранить». «Сейчас» вводите при каждой сверке с брокером |
| Добавить движения по счёту (фандинг, комиссии за перенос, PayOut, прибыль и убыток, переводы) | Внизу «Добавить движения по счёту»: вставьте строки из выписки брокера. Повторы пропускаются |
| Исключить запись из статистики или удалить ошибочную | Таблица «Движения по счёту за месяц»: у каждой строки кнопки «не учитывать» и «удалить» |
| Внести результат форекс-ноги за день | Внизу «Добавить форекс-результат»: дата и сумма в USDT (убыток со знаком минус). Если cTrader подключён, это нужно только для правок |
| Совместить рублёвую и форекс-ноги в точную сумму | В том же окне заполните «Сумма в ₽»: рубли будут зафиксированы вместо курса ЦБ |
| Поправить результат дня, не трогая реальные деньги | Добавьте строку со словом «Корректировка» в «Добавить движения по счёту», например `2026-09-14  +10 996 ₽  Корректировка рублёвой ноги`. Она учитывается только в статистике, в капитал не входит |
| Убрать перевод между счетами из статистики | Строки «Перевод средств» не считаются прибылью. Чтобы полностью убрать такую запись, нажмите «не учитывать» |

Ручной результат форекса за день важнее данных cTrader за этот же день. Отметка «ПЕРЕЛИВ» ставится
сама: это день, когда прибыль рублёвой ноги компенсирована убытком форекс-ноги (убыток 50–150%
от прибыли).

## Настройки под себя

Скопируйте `cscalp_settings.example.json` в `cscalp_settings.json` и измените нужное
(после правки перезапустите дневник):

- `log_root` — папка с логами, если терминал установлен не по умолчанию.
- `instruments` — шаг цены (`step`) и его стоимость в рублях (`step_value`) по каждому инструменту.
  Без этого прибыль по инструменту считается в пунктах, а не в рублях.
- `commission` — модель комиссий: `clearing_per_lot`, `taker_multiplier` и сбор за регистрацию
  `reg_fee` по инструментам. Значения в примере подобраны под один проп-привод, у вашего они могут
  отличаться, сверьте их с выпиской брокера.

## Фон

В дневнике на тёмной теме стоит фото рабочего стола: файл `cscalp_journal/static/bg.jpg`.
Чтобы сменить фон, замените его своей картинкой с тем же именем (JPEG), чтобы убрать, удалите файл.

## Telegram (по желанию)

Скопируйте `telegram.json.example` в `telegram.json`, впишите токен своего бота (у @BotFather)
и id канала. Публикация идёт вручную кнопками на странице связки.

## cTrader (по желанию)

Автоматическая подтяжка форекс-результатов через cTrader Open API. У каждого свои ключи:

1. На портале Open API (openapi.ctrader.com) войдите под своим cTrader ID, откройте **Applications**
   и создайте приложение. Redirect URI: `http://127.0.0.1:8777/ctrader/callback`.
2. Скопируйте `ctrader.json.example` в `ctrader.json` и впишите Client ID и Client Secret.
   Никому их не показывайте.
3. Подождите, пока приложение получит статус **Active** (проверка Spotware, обычно до 3 рабочих дней).
4. На странице «Итоги месяца» нажмите «Подключить cTrader» и разрешите доступ.

Модуль cTrader `start.bat` ставит сам и по необязательной схеме: если он не поставился, дневник
всё равно запускается, а внизу страницы отчёта будет сообщение «Модуль cTrader не установлен».
Устанавливать Visual C++ не нужно.

Дальше закрытые позиции подтягиваются каждые 15 минут. Читается только реальный счёт и только
чтение, торговать дневник не может.

## Обновление

Скачайте новый архив и распакуйте поверх, **не удаляя** папку `data/` и файлы `*.json`
(ваши настройки и база).

## Если что-то не работает

- Сообщение «Python 3.12 or newer was not found»: установите Python (с галочкой PATH) и запустите `start.bat` снова. Сообщения самого `start.bat` английские, это нормально.
- Ошибка «Microsoft Visual C++ 14.0 or greater is required» при установке: у вас старая версия
  `start.bat`. Скачайте свежий архив, в нём эта проблема исправлена.
- Пустой дневник: проверьте путь к логам (`log_root`) и что терминал уже писал логи за эти дни.
- Адрес не открывается: порт 8777 занят другой программой. Задайте другой перед запуском:
  в командной строке `set CSCALP_WEB_PORT=8780`, потом `start.bat`.
- Цифры в рублях не сходятся с брокером: проверьте `instruments` и `commission` в настройках.
