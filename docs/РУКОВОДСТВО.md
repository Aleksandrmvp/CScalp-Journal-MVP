# Руководство по работе с дашбордом

Подробный разбор всего интерфейса CScalp Journal: каждый экран, таблица и поле. Про установку и запуск см. [README](../README.md).

Дашборд открывается по адресу <http://127.0.0.1:8777> (локально) или <http://localhost:8777> (Docker) и состоит из **двух страниц**:

1. **Главная** — позиции, список арбитражных связок, журнал действий, настройки Telegram.
2. **Страница связки** — детали одной арбитражной связки (открывается кликом по её названию).

Данные обновляются автоматически: главная — раз в 3 секунды, страница связки — раз в 5 секунд. Ничего вручную перезагружать не нужно.

### Шапка и сводка за день

Верхняя строка. Слева направо:

- **CScalp Journal** — заголовок.
- **Сводка за сегодня**, например: `сделок: 46   maker:33 taker:13   ·   за день (net): −5 348,64 ₽ (−528,59 ₽ комиссия)`
  - `сделок: N` — сколько исполнений (FILL) было сегодня.
  - `maker:X taker:Y` — разбивка исполнений по ликвидности.
  - `за день (net): … ₽` — реализованный PnL за сегодня **за вычетом комиссии** (зелёный — плюс, красный — минус). Себестоимость позиций тянется с прошлых дней, но в сумму попадает только сегодняшний реализованный результат.
  - `(−… ₽ комиссия)` — оценка комиссии за день. Если рядом стоит `занижена — нет биржевого сбора для …`, значит по этим инструментам ещё не задан биржевой сбор для тейкера (см. [Словарь](#словарь-терминов)).
  - `(часть в пунктах)` — появляется, если для какого-то инструмента не задана стоимость шага цены, и его PnL считается в пунктах, а не в рублях.
- **Часы** — текущее время.
- **🌓** — кнопка переключения светлой/тёмной темы.

### Открытые позиции

Что сейчас в рынке — по данным самого терминала (`OnPositionUpdate`), а не реконструкция из сделок.

| Колонка | Что показывает |
|---|---|
| **Инструмент** | Тикер (напр. `FUT.CNYRUBF`) |
| **Позиция** | Чистый объём (нетто). Зелёный — лонг (>0), красный — шорт (<0), серый — флэт |
| **Ср. цена** | Средняя цена позиции по терминалу |
| **Реализ., ₽** | Реализованный за день PnL по инструменту (в рублях по стоимости шага) |
| **Сделок** | Число исполнений по инструменту |

Инструменты с нулевой позицией в таблице не показываются.

### Арбитражные связки (список)

Связка — это вручную собранная арбитражная структура (набор ног). Одна связка может переоткрываться много раз; здесь — общая сводка, детали внутри.

**Строка создания:**
- Поле **«Название связки»** — введите имя (напр. `CNYRUBF/CNY-12.26`).
- **«Создать из выбранных (N)»** — создаёт связку из сделок, отмеченных чекбоксами в журнале ниже. N — сколько сейчас отмечено.

**Таблица связок:**

| Колонка | Что показывает |
|---|---|
| **Связка** | `#id Название ↗` — ссылка на страницу связки |
| **Статус** | Зелёное `открыта` — есть открытая позиция; `нет позиции` — все циклы закрыты |
| **Сделок** | Сколько арб-сделок (циклов open→close) было в связке |
| **Общий PnL** | Суммарный реализованный PnL (net) по всем циклам; `₽` или `п.` (пункты) |
| **Открытые ноги** | Если связка открыта — какие ноги и в каком объёме сейчас держатся |
| **Раздвижка** | Значение формулы в `%`. **Если форекс-ноги нет** — показывается синтетическая цена с подписью пары, напр. `USDRUBF/CNYRUBF = 6,722` |
| (кнопки) | **`+ выбр. (N)`** — добавить отмеченные в журнале сделки в эту связку; **`✕`** — удалить связку |

### Журнал действий

Единая хронология всех действий. По умолчанию показаны только исполнения (**FILL**).

**Панель фильтров:**
- **Инструмент** — выпадающий список (заполняется автоматически из данных).
- **Событие** — `SUBMIT` (выставление заявки), `CANCEL` (снятие), `FILL` (исполнение). По умолчанию `FILL`.
- **Сторона** — `Buy` / `Sell`.
- **Ликвидность** — `maker` / `taker` / `unknown`.
- **«сбросить»** — сбрасывает все фильтры.
- `показано: X из Y` — сколько строк проходит фильтр.
- Справа: **«На странице»** (50/100), стрелки **←/→** и номер страницы.

**Таблица:**

| Колонка | Что показывает |
|---|---|
| ☐ | Чекбокс — только у исполнений (FILL); отмечайте, чтобы собрать связку |
| **Инструмент** | Тикер |
| **Время** | Время события (ЧЧ:ММ:СС.ммм) |
| **Событие** | SUBMIT / CANCEL / FILL |
| **Сторона** | Buy (зелёный) / Sell (красный) |
| **Цена**, **Кол-во** | Цена и объём |
| **Ликвидность** | Тег maker/taker/unknown (для исполнений) |
| **Связка** | Бейджи связок, в которые входит эта сделка (ссылки) |

### Telegram-канал

Карточка настройки постинга:
- Статус подключения (токен/канал заданы или нет).
- Поле **id канала** (`@канал` или `-100…`) + **«Сохранить канал»**.
- **«Тест»** — отправляет тестовое сообщение в канал.
- Подпись: *автопостинг отключён — публикация только вручную кнопками 📢 на странице связки.*

## Страница связки

Открывается кликом по названию связки. Вверху: **← Журнал** (назад), `#id Название`, **✎** (переименовать), справа **🌓** (тема).

![Страница связки](screenshots/bundle.webp)

### Формула раздвижки

Задаёт, как считается «раздвижка входа» в процентах. Нотация как в TradingView.

- **Поле ввода** — например `RUS:GLDRUB.P/RUS:SI1!*31.1/RUS:GD1!*100000`.
- **«Сохранить»** — применяет формулу (пересчёт сразу).
- **Строка сопоставления** под полем — показывает, как символы формулы легли на ноги: `RUS:GLDRUB.P → FUT.GLDRUBF (11 270,4)`. Метки: **синт.** — цена посчитана синтетически (нет форекс-ноги), **=1** — символ не сопоставлен и подставлен как 1.
- Поддерживаются `+ − * / ( )`. Символы сопоставляются с ногами по тикеру; короткие коды MOEX распознаются (CR→CNY, GD→GOLD, SI→Si, CNYRUB→CNYRUBF и т.д.).
- Если формула пустая или нога не покрыта — рамка поля краснеет, а непокрытая нога подсвечивается в списке ног.

### Итог по связке

Ключевые показатели (KPI):
- **Статус** — `Открыта` / `Нет позиции`.
- **PnL (net)** — суммарный результат за вычетом комиссии.
- **Комиссия** — суммарная комиссия по связке.
- **Арб. сделок** — число циклов open→close.

Если для инструмента не задана стоимость пункта — под KPI появится предупреждение, что PnL в пунктах.

### Траектория PnL

График накопленного PnL по всем сделкам связки. Точки раскрашены по типу действия; при наведении — подсказка (какая сделка, действие, инструмент, цена×объём, PnL Σ).

Легенда:
- 🟢 **OPEN** — открытие цикла,
- 🔵 **ADD** — добавление к позиции,
- 🟠 **REDUCE** — частичное закрытие,
- 🔴 **CLOSE** — полное закрытие цикла.

### Арбитражные сделки

Связка автоматически сегментируется на отдельные арб-сделки — циклы от «все ноги в нуле» до «все ноги в нуле». Каждый цикл — отдельный блок.

**Заголовок сделки:**
- `Сделка #N` + статус (`открыта` / `закрыта`).
- Диапазон времени `вход → выход` (или `…`, если ещё открыта).
- `PnL … ₽` (net) и, если есть, `(−… комис.)`.
- `раздвижка входа: …%` — значение формулы на входе.
- **📢 открытие** / **📢 закрытие** — опубликовать событие в Telegram-канал вручную (закрытие доступно только у закрытых сделок).
- Если сделка открыта — строка `открыто: тикер объём @ цена` по каждой ноге.

**Таблица событий сделки:**

| Колонка | Что показывает |
|---|---|
| **Время** | Время исполнения |
| **Действие** | OPEN / ADD / REDUCE / CLOSE |
| **Площадка** | `CScalp` для внутренних ног, площадка форекса — для внешних |
| **Инструмент**, **Сторона**, **Цена**, **Кол-во** | Параметры исполнения |
| **Ликв.** | maker/taker |
| **Нетто** | Позиция по этой ноге после исполнения |
| **PnL ногой** | Реализованный PnL этим исполнением |
| **PnL Σ** | Накопленный PnL по сделке |
| **✕** | Убрать это исполнение из связки (внешнюю ногу — удалить, внутреннюю — открепить) |

### Ноги связки

Управление составом связки. Блок пагинируется по 20.

**Форма «внешняя нога»** (для форекс-хеджа, которого нет в логах терминала):
- **Инструмент** (напр. `usdcnh`), **Сторона** (Buy/Sell), **Цена**, **Кол-во**, **Площадка** (по умолч. `forex`), **Время** (ЧЧ:ММ:СС).
- **«+ добавить»** — добавляет ногу.

**Таблица ног:** Площадка, Инструмент, Сторона, Цена, Кол-во, Время, **✕** (удалить).
Нога, не сопоставленная с формулой, подсвечивается красным и помечается **⚠ не в формуле**.

### Нераспределённые сделки

Исполнения (FILL), ещё не закреплённые ни за одной связкой. Блок пагинируется по 20.
Кнопка **`+`** в строке добавляет сделку в **текущую** связку.

## Переключение темы

Кнопка **🌓** в шапке (на обеих страницах) переключает светлую/тёмную тему. Выбор запоминается в браузере и применяется на всех страницах.

## Словарь терминов

- **Мейкер / тейкер** — вычисляется из времени жизни заявки в стакане (флага в логах нет): быстрое исполнение ≈ тейкер, «отстоявшаяся» заявка ≈ мейкер. На неликвидных инструментах определение приблизительное.
- **Раздвижка** — значение вашей формулы в процентах; насколько «разъехались» ноги на входе.
- **Синтетика** — цена форекс-пары, вычисленная из ног MOEX, когда реальной форекс-ноги в связке нет (напр. USDCNH ≈ USDRUBF / CNYRUBF).
- **net** — результат за вычетом комиссии.
- **Пункты vs рубли** — если для инструмента задана стоимость шага цены, PnL в рублях; иначе — в пунктах (`п.`).
- **Цикл (арб-сделка)** — период от полного отсутствия позиции по всем ногам до следующего такого же состояния.
